Original HarfBuzz shaping supplies glyph IDs and within-cluster positioning;
captured native SVG characters supply cluster anchors. Source-owned checked
selector SFNTs supply the glyph SVG font definitions. No artwork RGB is read
from SVG/Canvas: ordered composition uses captured source-linear Float32 RGBA.
Unsupported or mismatched lines return no paint primitives. Native character
addressing alone is not a glyph identification contract.

The first Canvas-gated attempt exposed real SVG/Canvas advance differences.
SVG cluster anchoring and native SVG glyph paint fixed the geometric fixtures.
A complete Manrope affine/center line then exposed rounded native caret
coordinates. Equivalent matrix/local-origin projections and a separate native
screen-font projection now cover that case without widening pixel tolerances.
Original nominal font advances separate GPOS from native measured advances;
independently captured native em metrics retain computed-size positioning.
Coordinates/axes are not fitted from reference pixels. The screen projection
currently excludes optical-axis sources; other verified projections cover the
optical fixture. This is a checked dependency, not universal native selection.

The difficult screen-font path is checked against an independently generated
complete Manrope glyph font at source alphas 0.5, 0.64123012345 and 1e-8.
That comparison verifies glyph coverage and exact Float32 composition using
separately verified poses; it does not independently reconstruct native poses.
FontTools 4.51.0 retains original glyph coordinates, components, metrics and
variation tables. GSUB/GPOS are equivalently recompiled, not byte-identical.
This Manrope source has no per-glyph instruction bytes; the independent reference
does not prove nonzero hint-program equivalence. Original SIL OFL terms accompany
the reference fixture; application runtime fonts are unchanged.

The production checks run the actual emitted nominal shaping worker and SVG
coverage module. Prepared fixture adapters isolate these components; the native
source matrix separately verifies complete source ownership and line matching.
Every image/font reader and measurement probe retires on faults; healthy retries
succeed. Source/model/history and public scripting/REST/plugin contracts retain
their existing boundaries.

Reported SVG bounds define the checked domain. Universal font ink extents,
all native/legacy/optical hosts, styled/bidi/script/font fallback, missing and
intrinsic paint, path/vertical layouts, connected float TextLayer authoring,
scenes/export/shared transport/persistence and all unfinished original quality,
