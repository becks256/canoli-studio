# Linear float wet-paint foundation — 2026-10-31

Status: verified numerical/worker implementation increment from `5f858d0`.
The complete original implementation-roadmap goal remains active.

The private native pixel engine now loads straight linear Float32 pixels into
premultiplied carried pigment, deposits and picks up from pre-deposit source
pixels, and applies final completed-stroke selection/opacity. Finite signed/HDR
RGB and sub-byte alpha never pass through a byte canvas or normalized-RGB
clamp. Float64 arithmetic stores float32 once.

[Equations, defaults, ownership, errors and budgets](../FLOAT_PROCESSING.md#linear-float-wet-paint-primitives)
are private engine contracts. No public constructor, document schema, isolated
service, REST route, plugin grant or float Smudge/Mixer admission is added. The
actual float tool gate remains closed. Byte-session/PNG replacement storage
still needs a separate HDR counterpart.
